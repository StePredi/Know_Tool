1 · Schema di rete (nuovo tipo di disegno «rete»)

Le righe si leggono dall'alto in basso. Le linee portano i nomi delle porte; il colore dice la VLAN; il trunk ha tutte le strisce. Il file si scrive a mano (vedi il testo sotto).

Come si scrive nel file della scheda


Per ora non c'è: spostamento dei nodi con il mouse (le posizioni le decide il codice dalle righe), onde Wi-Fi, più di un cavo fra gli stessi due nodi.





2 · Modificare una spiegazione a moduli


Prova: scegli un blocco a sinistra, cambia il testo, sposta con ↑ ↓, elimina con ✕, aggiungi con «+ Blocco». A destra il modulo cambia in base al tipo di blocco. Si salva solo se il file rispetta lo schema (come adesso per le ricette).
